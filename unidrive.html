UniDrive unified cloud storage

A local-first storage pooler that combines multiple Google Drive accounts and S3-compatible buckets into one virtual vault — chunking oversized files across drives and streaming them back with full seek support.

Inside the product

One vault across every storage account

UniDrive routes each upload to the account with the right free space, splits oversized files across drives, and keeps only a tiny index on the server.

01
📁

Unified storage pools

Connect several Google Drive accounts and S3 providers — AWS S3, Cloudflare R2, Wasabi, Backblaze B2, MinIO — with combined quota tracking.

Multi-account · Combined quota
02
📦

Dynamic chunked uploads

Files larger than a single account's free space are split into 500 MB–1 GB parts and dispatched by most-available, round-robin, or priority routing.

500 MB–1 GB parts · Smart routing
03
▶️

Streaming and previews

HTTP 206 range requests across chunk boundaries power in-app previews for images, video, audio, PDFs, and text.

Range seeking · Universal viewer
04
🔐

Security first

Argon2 password hashing, JWT access and refresh tokens, hashed refresh tokens, and encrypted provider tokens at rest.

JWT · Argon2 · Encryption
05
🔗

Sharing and API access

Virtual folders, public share links with hashed tokens, per-user invites, and external upload API keys.

Folders · Shares · API keys
06
🛡️

Disaster recovery

A sealed, per-user encrypted vault manifest is synced to storage so the entire file, chunk, and account topology can be rebuilt after data loss.

Vault manifest · Zero server disk
Build facts

Full-stack from database to UI

01Backend

Express 5 + TypeScript API with Prisma over embedded SQLite in WAL mode — no external database.

02Frontend

React 19 + Vite + Tailwind CSS with storage-pool views and an in-app preview stage.

03Auth

Email/password and Google sign-in with automatic first-drive connection.

04Storage

Files stream straight through to providers and are never written to server disk.
